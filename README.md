# NexaCalc 🎀

A sleek, pink-themed scientific calculator built for quick everyday calculations and a little extra style.

## Features
- Basic arithmetic: addition, subtraction, multiplication, and division
- Scientific functions: sine, cosine, tangent, inverse trig functions, square root, natural log, and base-10 log
- Constants: π and e
- Powers, percentages, absolute value, and sign toggle
- Calculation history for the current session
- Keyboard support
- Responsive layout for desktop and mobile

## Run locally
1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Start calculating!

No build step or package installation is required.

## Files
- `index.html` — page structure and calculator keypad
- `style.css` — responsive pink-themed design
- `script.js` — calculator logic and calculation history

## Note
This is a standalone recreation based on the publicly visible NexaCalc website design and functionality. It is not the original source code exported from Lovable.
